## 🌌 Overview

**Space Themed Portfolio** is a modern and immersive personal portfolio built to showcase projects, skills, experience, and creativity through a premium cosmic UI.

Built with **Next.js, TypeScript, TailwindCSS, Framer Motion, and modern frontend practices**, this portfolio focuses on:

- ✨ Premium UI/UX
- 🚀 Smooth animations & interactions
- 🌌 Space-inspired futuristic visuals
- 📱 Fully responsive experience
- ⚡ High performance & clean architecture
- 🎯 Recruiter-friendly portfolio structure

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/the-rishav01580/space-themed-portfolio.git
```

### 2. Navigate into project

```bash
cd space-themed-portfolio
```

### 3. Install dependencies

```bash
npm install
```

or

```bash
yarn install
```

---

### 4. Run development server

```bash
npm run dev
```

Now open:

```bash
http://localhost:3000
```

---

## ⚙️ Environment Setup

If environment variables are required:

Create a `.env.local` file:

```env
NEXT_PUBLIC_APP_URL=http://localhost:3000
```
